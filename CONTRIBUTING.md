# Contributing

Use fictional data in issues, tests and screenshots. Never attach a real notification database, credentials, a settings backup, or a desktop screenshot containing other applications.

Run the unit tests and JavaScript syntax check listed in the README. New shell features should be checked in GNOME 50 and document compatibility limits. Keep model calls off the UI loop, keep local-only mode free of network calls, and retain the distinction between ordinary attention and severe incidents.

Report problems through the repository's issue tracker with a minimal sanitized reproduction. Include the shell/Python version and whether the native GNOME gate or GTK fallback was in use.
